RvCarbon API 1.0.0 Busca de Usuários

[ Base URL: https://api.rvcarbon.com.br/ ]

Módulo dedicado à pesquisa de usuários registrados no sistema. Útil para funcionalidades de convite de membros para Fazendas ou transferência de titularidade de Proprietários. *(Nota: Para criar, atualizar dados ou deletar contas, veja o módulo Auth/Me).*

User Controller Pesquisa e Listagem
GET /api/users/search Buscar Usuários por Username
Comportamento da Busca: Esta rota pesquisa usuários cujo nome de usuário (username) comece com as letras informadas no parâmetro (Ignorando se é letra maiúscula ou minúscula).
Se o parâmetro for enviado vazio, o sistema não gera erro, ele retorna uma lista paginada vazia de forma segura.
Parâmetros (Query Params)
NomeObrigatórioDescrição
usernameSimO texto ou prefixo a ser buscado (Ex: "joao" trará "joaosilva", "joao123").
pageNãoPágina dos resultados. Padrão: 0.
sizeNãoQuantidade de usuários por página. Padrão: 5.
Respostas Possíveis
200 Sucesso: Retorna uma lista paginada de objetos simplificados (UserSearchDTO), ideal para exibir em menus dropdown.
400 Requisição Inválida: Ocorre se você esquecer de passar a propriedade obrigatória ?username= na URL da rota.
401 Não Autorizado: Requer usuário logado no sistema.
Schemas (Modelos de Dados)
