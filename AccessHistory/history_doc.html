RvCarbon API 1.0.0 Histórico de Acessos

[ Base URL: https://api.rvcarbon.com.br/ ]

Módulo responsável por registrar e listar as navegações e acessos importantes (Histórico) realizados pelo usuário. Todos os registros são privados e vinculados diretamente ao usuário autenticado.

Access History Controller Auditoria e Histórico de Navegação
POST /api/history/ Registrar Novo Acesso
Cria um novo registro no histórico do usuário. O sistema detecta quem está chamando a API através do Token de Acesso (Bearer Token) e vincula este evento automaticamente à conta dele.
Exemplo de Requisição (JSON)
{
  "url": "https://app.rvcarbon.com.br/dashboard",
  "urlImage": "https://app.rvcarbon.com.br/assets/dash-icon.png",
  "label": "Acesso ao Dashboard Principal"
}
Respostas Possíveis
200 Sucesso: Retorna o registro recém salvo. 
{
  "id": 1024,
  "userId": 15,
  "url": "https://app.rvcarbon.com.br/reports",
  "urlImage": "https://app.rvcarbon.com.br/assets/report.png",
  "label": "Visualizou Relatórios",
  "createdAt": "2023-11-20T14:30:00Z"
}
400 Erro na Requisição: O JSON enviado está mal formatado ou não pôde ser processado.
401 Não Autorizado: Você esqueceu de enviar o Token de Acesso, ou ele expirou.
GET /api/history/ Listar Meu Histórico (Paginado)
Busca todos os registros de acesso atrelados ao usuário logado, ordenados do mais recente para o mais antigo (Decrescente por Data de Criação).
Parâmetros (Query Params)
NomeObrigatórioDescrição
pageNãoPágina a ser consultada. Padrão: 0.
sizeNãoQuantidade de itens por página. Padrão: 5.
Respostas Possíveis
200 Sucesso: Retorna um Objeto Paginado (Page<AccessHistoryResponse>) contendo os registros do usuário.
401 Não Autorizado: Requer usuário logado no sistema (Token válido).
Schemas (Modelos de Dados)
CreateAccessHistoryRequest (Dados de Envio) ▼
url: string // A rota ou link acessado
urlImage: string // Imagem de referência ou ícone da rota
label: string // Nome descritivo da ação/página
AccessHistoryResponse (Dados de Retorno) ▼
id: long
userId: long
url: string
urlImage: string
label: string
createdAt: string($date-time)
