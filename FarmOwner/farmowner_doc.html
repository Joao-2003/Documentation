RvCarbon API 1.0.0 Fazendas

[ Base URL: https://api.rvcarbon.com.br/ ]

Gestão de Proprietários (Farm Owners). O Proprietário é a entidade raiz à qual as fazendas pertencem. Neste módulo você pode cadastrar, alterar e transferir a responsabilidade sobre esses proprietários.

Farm Owner Controller Gestão de Proprietários de Fazendas
POST /api/owners/ Criar Novo Proprietário
Cria o registro de um Proprietário de Fazendas (Pessoa Física ou Jurídica). O usuário autenticado que criar este registro se torna automaticamente o responsável por ele.
⚠️ Regras de Validação:
  • name: Obrigatório. Entre 3 e 150 caracteres.
  • cpfCnpj: Obrigatório. Deve estar formatado e ser válido (ex: 000.000.000-00).
  • phone: Deve estar no formato (XX) XXXXX-XXXX.
  • state e city: Estado e Cidade são obrigatórios.
  • email: Obrigatório, deve ser válido e ter ao menos 5 caracteres.
  • birthDateFoundation: Obrigatória. Data de nascimento/fundação deve estar no passado. (Formato: yyyy-MM-dd).
Exemplo de Requisição (JSON)
{
  "name": "Agro Pecuária Silva",
  "cpfCnpj": "12.345.678/0001-99",
  "phone": "(64) 99999-1234",
  "state": "GO",
  "city": "Rio Verde",
  "email": "contato@agrosilva.com.br",
  "birthDateFoundation": "1998-05-15",
  "profileImageUrl": "https://linkdafoto.com"
}
Respostas Possíveis
200 Sucesso: Retorna o perfil do Proprietário recém-criado.
400 Erro de Validação: Se os dados não respeitarem o padrão. 
{
  "cpfCnpj": "O CPF ou CNPJ (cpfCnpj) está em formato inválido.",
  "birthDateFoundation": "A data de nascimento ou fundação (birthDateFoundation) deve estar no passado."
}
GET /api/owners/ Listar Meus Proprietários
Retorna uma lista com todos os Proprietários de Fazenda pelos quais o usuário autenticado é responsável ou membro da equipe.
Respostas Possíveis
200 Sucesso: Retorna uma lista de Array `[ { ... } ]`.
GET /api/owners/{ownerId}/ Ver Detalhes do Proprietário
Respostas Possíveis
200Sucesso: Retorna os dados completos.
404 Não Encontrado: O Proprietário não existe. 
{
  "detail": "FarmOwner não encontrado com o id fornecido."
}
PATCH /api/owners/{ownerId}/ Atualizar Dados do Proprietário
⚠️ Regras Importantes:
  • Permissão (403): Apenas o usuário definido como Responsável deste proprietário pode fazer alterações.
  • Atualização Parcial: Todos os campos são opcionais. Envie apenas o que deseja mudar.
  • Formatos: Se enviar CPF, Telefone ou E-mail, eles passarão pelas validações de formato rígidas.
Exemplo de Envio (JSON)
{
  "phone": "(64) 98888-0000",
  "city": "Jataí"
}
Respostas Possíveis
200Sucesso: Proprietário atualizado.
400Erro de Validação: Os formatos enviados (email, telefone, etc.) estão errados.
404Não Encontrado: O ID do Proprietário não existe no sistema.
403 Proibido: Você não é o responsável por este proprietário. 
{
  "detail": "Você não possui autorização sobre este Proprietário de Fazenda."
}
DELETE /api/owners/{ownerId}/ Excluir Proprietário
Exclui permanentemente o Proprietário.
Permissão: Apenas o Usuário Responsável pelo Proprietário pode excluí-lo.
Respostas Possíveis
200Sucesso: Removido (O controller retorna 204 No Content).
404Não Encontrado: ID não existe.
403Proibido: Apenas o responsável tem permissão de exclusão.
PUT /api/owners/{ownerId}/transfer/ Transferir Responsabilidade (Único)
Transfere a responsabilidade e o gerenciamento de UM proprietário específico para outro usuário do sistema. Isso reflete também em todas as fazendas atreladas a esse proprietário (o novo usuário se torna o gerente das fazendas).
Dados para Envio (TransferUserResponsibleRequest)
{
  "userResponsibleUserName": "username_do_novo_responsavel"
}
Respostas Possíveis
200Sucesso: Transferência concluída. (Sem corpo de retorno).
404 Não Encontrado: O Proprietário não existe OU o "username_do_novo_responsavel" digitado não existe no sistema.
403Proibido: Apenas o responsável atual pode fazer esta transferência.
PUT /api/owners/transfer-all/ Transferir Todos os Proprietários
Transfere a responsabilidade de TODOS os proprietários que pertencem a você para outro usuário do sistema.
Dados para Envio (TransferUserResponsibleRequest)
{
  "userResponsibleUserName": "username_do_novo_responsavel"
}
Respostas Possíveis
200Sucesso: Transferência em lote concluída.
404Não Encontrado: O usuário de destino (username) não existe.
