Documentação oficial da API RvCarbon.
Este documento descreve os recursos de Autenticação, cobrindo o ciclo de vida do usuário (cadastro, login, exclusão) e suas respectivas regras de negócio.

Termos de Serviço | Contato Suporte
Auth Controller Autenticação e Gestão de Contas
POST /api/auth/login/ Login e emissão de tokens
Regra de Negócio:
  • O sistema verifica as credenciais (usuário e senha).
  • Gera um par de chaves de acesso (Token de Acesso e Token de Atualização).
  • Bloqueio de Segurança: O login será recusado se o e-mail do usuário ainda não tiver sido confirmado.
Request Body
{ "loginIdentifier": "user@rvcarbon.com", // Aceita E-mail ou Nome de Usuário "password": "*******" }
Responses
CodeDescription
200 Sucesso. Retorna as chaves de acesso.
Retorno: JwtTokenPair
401 Credenciais (login ou senha) incorretas.
403 Conta inativa. É necessário confirmar o e-mail antes de realizar o login.
POST /api/auth/register/ Cadastro de novo usuário
Comportamento: Realiza o pré-cadastro do usuário. O status inicial é definido como "Pendente". Um e-mail contendo um link de ativação é enviado automaticamente para o endereço informado.
Request Body (AuthRegisterRequest)
{ "name": "João Silva", "email": "joao@email.com", "phone": "(11) 99999-9999", // Formato obrigatório: (xx) xxxxx-xxxx "username": "joaosilva", "password": "secret123", // Mínimo 6 caracteres "birthday": "1990-01-01", "state": "SP", "city": "São Paulo", "cpfCnpj": "123.456.789-00", // Deve ser um CPF ou CNPJ válido "occupation": "Agrônomo", "academicTitle": "Doutor", "imageProfileUrl": "http://..." }
Responses
200 Pré-cadastro realizado. E-mail de confirmação enviado.
400 Erro de validação nos dados enviados (ex: CPF inválido, e-mail mal formatado).
POST /api/auth/refresh/ Renovar sessão (Token)
Segurança: Utilizado para manter o usuário logado sem pedir a senha novamente.
  • Invalida o token de atualização anterior (rotação de chaves).
  • Se o token antigo já tiver sido invalidado ou expirado, a renovação falha e o usuário deve fazer login novamente.
Request Body
{ "refreshToken": "eyJhbGciOiJIUzI1NiJ..." }
Responses
200Sessão renovada. Retorna novo par de tokens.
401Sessão expirada ou inválida. Necessário realizar login novamente.

DELETE /api/auth/me/ Solicitar Exclusão de Conta
Regra de Integridade de Dados:
  • O sistema verifica se o usuário é proprietário de Fazendas cadastradas.
  • Se possuir vínculos: A exclusão é impedida para evitar que fazendas fiquem "órfãs" no sistema.
  • Se não possuir vínculos: Um e-mail de confirmação final é enviado para garantir a intenção do usuário.
Responses
204Solicitação aceita. Verifique seu e-mail para confirmar a exclusão.
403Operação negada: O usuário possui fazendas vinculadas e não pode ser excluído.
Fluxos de Recuperação (Senha / Confirmação)
POST /api/auth/forgot-password/ Recuperar Senha
Request Body
{ "email": "user@email.com" }
Responses
200Se o e-mail existir, um link de recuperação será enviado.
POST /api/auth/reset-password/ Definir Nova Senha
Validação: A nova senha não pode ser idêntica à senha atual por motivos de segurança.
Request Body
{ "token": "token_recebido_no_email", "newPassword": "NovaSenh@123" }
Responses
200Senha alterada com sucesso.
400Erro: A nova senha é igual à atual ou o link expirou.
