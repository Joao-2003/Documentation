Documentação oficial da API RvCarbon.

Auth Controller Autenticação e Gestão de Contas
POST /api/auth/login/ Entrar no Sistema
O que isso faz? Verifica se o e-mail/username e a senha estão corretos. Se estiverem, entrega uma "Chave de Acesso" (Token).
⚠️ Regras de Validação:
  • loginIdentifier: Obrigatório (E-mail ou Username).
  • password: Obrigatório, Mínimo 6 caracteres.
Dados para Envio (JSON)
{
  "loginIdentifier": "user@rvcarbon.com",
  "password": "*******"
}
Respostas Possíveis
CódigoExplicação e Retorno
200 Sucesso (Login Aprovado): Retorna suas chaves de acesso.
{ "token": "...", "refreshToken": "...", "tokenType": "bearer" }
400 Erro na Requisição: Falta preencher campos ou JSON inválido.
// JSON mal formatado ou corpo vazio:
{ "detail": "JSON inválido." }

// Campos vazios:
{
  "password": "não deve estar em branco",
  "loginIdentifier": "O e-mail ou username é obrigatório."
}
401 Não Autorizado: Credenciais incorretas.
{ "details": "Usuário inexistente ou senha inválida" }
403 Acesso Negado: Usuário inativo. Necessário confirmar e-mail.
{ "details": "User was not activated. Please check your email..." }
POST /api/auth/register/ Criar Nova Conta
⚠️ Regras Rigorosas de Validação (Erro 400 se falhar):
  • name: Min 3 letras.
  • email: Formato válido e Min 5 letras.
  • phone: Formato exato: (XX) XXXXX-XXXX.
  • username: 3 a 30 caracteres.
  • password: Mínimo 6 caracteres.
  • birthday: Formato yyyy-MM-dd e deve ser no passado.
  • cpfCnpj: Formato válido (ex: 000.000.000-00 ou 00.000.000/0000-00).
  • state, city: Obrigatórios.
  • occupation, academicTitle: Min 2 letras.
  • imageProfileUrl: Min 5 letras.
Formulário de Cadastro
{
  "name": "João Silva",
  "email": "joao@email.com",
  "phone": "(11) 99999-9999",
  "username": "joaosilva",
  "password": "secret123",
  "birthday": "1990-01-01",
  "state": "SP",
  "city": "São Paulo",
  "cpfCnpj": "123.456.789-00",
  "occupation": "Agrônomo",
  "academicTitle": "Doutor",
  "imageProfileUrl": "http://..."
}
Respostas Possíveis
200 Sucesso (Cadastro Realizado): Retorna o usuário criado.
{
  "userId": 1, "name": "joao", "email": "jvglima03@gmail.com",
  "phone": null, "cpfCnpj": "999.999.999-99", "state": "go",
  "city": "rio quente", "birthday": "2003-03-20", ...
}
400 Erros de Validação (Campos Inválidos):
// Mapa Plano de Erros (Campo: Mensagem):
{
  "password": "A senha (password) deve ter no mínimo 6 caracteres.",
  "name": "O nome (name) deve ter pelo menos 3 caracteres.",
  "cpfCnpj": "O CPF ou CNPJ (cpfCnpj) está em formato inválido.",
  "email": "O email (email) deve ser válido."
}

// Erro de Parsing (Data/Tipo inválido):
{ "detail": "Campo 'birthday' tem valor inválido. Use o formato yyyy-MM-dd." }

// Duplicidade (E-mail/Username já existe):
{ "email": "email já está em uso.", "username": "username já está em uso." }
POST /api/auth/refresh/ Renovar Sessão
⚠️ Regras:
  • refreshToken: Obrigatório. É a chave secundária recebida no login.
{ "refreshToken": "string" }
Respostas Possíveis
200 Sucesso: Retorna um novo par de chaves de acesso.
{ "token": "...", "refreshToken": "...", "tokenType": "bearer" }
400 Erro na Requisição: Enviou Token errado (ex: AccessToken em vez de Refresh).
{ "detail": "O token informado é um AccessToken, mas esperava-se um RefreshToken." }
401 Não Autorizado: Chave inválida, expirada ou já usada (Blacklisted).
{ "detail": "Refresh token invalid or expired. Please make login again." }
POST /api/auth/logout/ Sair (Invalidar Token)
⚠️ Regras: Envie o refreshToken para invalidá-lo no banco e impedir novos acessos. 
{ "refreshToken": "string" }
Respostas
200Sucesso (Sem conteúdo de retorno).
400Erro: Enviou token errado (AccessToken).
401Erro: Token já invalidado anteriormente.

PATCH /api/auth/me/ Atualizar Meus Dados
⚠️ Regras Completas (Se enviar o campo, deve ser válido):
  • name: Mínimo 3 letras.
  • phone: Formato exato: (XX) XXXXX-XXXX.
  • state: Texto livre (não nulo).
  • city: Texto livre (não nulo).
  • birthday: Formato yyyy-MM-dd e deve ser no passado.
  • cpfCnpj: Formato válido (ex: 000.000.000-00 ou 00.000.000/0000-00).
  • occupation: Mínimo 2 letras.
  • academicTitle: Mínimo 2 letras.
  • imageProfileUrl: Mínimo 5 letras.
Dados para Atualizar
{
  "name": "Novo Nome",
  "phone": "(11) 99999-8888"
}
Respostas
200Sucesso: Retorna os dados do usuário já atualizados.
400Erro: Validação falhou (retorna mapa de erros igual ao cadastro).
DELETE /api/auth/me/ Excluir Minha Conta
Regra: Se o usuário for dono de Fazendas, lança erro (pois não pode deixar fazendas sem dono).
Respostas
204Aceito: E-mail de confirmação enviado. Verifique sua caixa de entrada.
400 Erro: Impossível excluir.
{ "detail": "Você não pode deletar sua conta tendo clientes associados" }
Fluxos de Recuperação (Senha / Confirmação)
Fluxo Completo de Reset de Senha:
1
Usuário envia E-mail para /forgot-password.
2
Backend envia e-mail contendo link: https://app.rvcarbon.com.br/reset-password?token=XYZ...
3
Usuário clica no link. Frontend abre, captura o token da URL.
4
Usuário digita a nova senha na tela.
5
Frontend envia token capturado + novaSenha para o endpoint /reset-password.
POST /api/auth/forgot-password/ Esqueci Minha Senha
  • email: Obrigatório e formato válido.
{ "email": "user@email.com" }
Respostas
200Sucesso: E-mail de recuperação enviado (se o usuário existir).
POST /api/auth/reset-password/ Salvar Nova Senha
  • token: Obrigatório (Vem no link do e-mail).
  • newPassword: Mínimo 6 caracteres.
{ "token": "...", "newPassword": "123456" }
Respostas
200Sucesso: Senha alterada.
400 Erro: Senha igual à atual.
{ "detail": "A nova senha não pode ser igual à senha atual." }
401 Erro: Token expirado ou inválido.
{ "detail": "Token de confirmação invalido ou expirado!" }
