RvCarbon API 1.0.0 Relatórios (HTML)

[ Base URL: https://api.rvcarbon.com.br/ ]

Este módulo é responsável por fornecer as telas de relatórios visuais geradas no lado do servidor (Server-Side Rendering).

⚠️ Aviso para Desenvolvedores Front-end: Diferente das rotas REST tradicionais que retornam dados puros em JSON, os endpoints desta seção retornam documentos HTML (text/html) completos (via Thymeleaf). Você deve utilizar estas rotas como fontes para <iframe>, navegação direta (nova aba), ou conversores de PDF.

Reports Controller Geração de Telas e Relatórios Visuais
GET /reports/emissions/{batchId}/ Relatório de Emissões GHG (HTML)
Comportamento: Este endpoint carrega os dados de um Lote de Emissões Específico (EmissionBatchGhg) e de todas as suas análises vinculadas, injetando-os no template emissionsGhg_report.html.
Requer autenticação válida (Bearer Token) para acesso aos dados do lote.
Parâmetros (Path)
NomeObrigatórioDescrição
batchIdSimO ID numérico do Lote de Emissão a ser detalhado.
Respostas Possíveis
200 Sucesso (text/html): Retorna o código-fonte da página HTML construída com os relatórios GHG.
404 Não Encontrado: O Lote (Batch) solicitado não existe.
401 Não Autorizado: Requer usuário autenticado para carregar os dados.
GET /reports/arva/{fieldId} Relatório ARVA por Talhão (HTML)
Comportamento: Busca o histórico de análises agrícolas (ARVA) de um Talhão específico, restrito a um período de tempo predeterminado pelas datas de início e fim enviadas na URL. O resultado compõe o template analysis_arva_report.html.
Parâmetros Obrigatórios
NomeLocalFormatoDescrição
fieldIdPathLongID numérico do Talhão.
startDateQueryyyyy-MM-ddData de início da consulta estatística.
endDateQueryyyyy-MM-ddData de fim da consulta estatística.
Respostas Possíveis
200 Sucesso (text/html): Página renderizada com as estatísticas do Talhão.
400 Erro de Requisição: Falha de formatação. Ocorre se o formato da data não for estritamente yyyy-MM-dd.
500 Erro Interno (Edge Case): Se nenhum lote for encontrado no período selecionado, a aplicação tentará acessar arvaBatchs.get(0) e lançará uma exceção (IndexOutOfBoundsException).
