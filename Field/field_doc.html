RvCarbon API 1.0.0 Talhões (Fields)

[ Base URL: https://api.rvcarbon.com.br/ ]

Gestão de Talhões (Fields). O Talhão é a área física de plantio dentro de uma Fazenda. Neste módulo você pode criar novos talhões manualmente, importá-los em lote via arquivo GeoJSON e gerenciar os polígonos.

Field Controller Gestão de Áreas de Cultivo e Polígonos
POST /api/fields/ Criar Novo Talhão Manualmente
Cria um novo Talhão dentro de uma Fazenda informando as coordenadas (polígono) ponto a ponto.
⚠️ Regras de Validação:
  • Permissão: Seu usuário deve ter a permissão de Gerenciamento da Fazenda (MANAGE_FARM).
  • farmId: Obrigatório. ID numérico da Fazenda pai. Deve ser positivo.
  • fieldName: Obrigatório. Nome do talhão com mínimo de 2 caracteres.
  • totalAreaHec: Obrigatório. Área total em hectares, deve ser maior que zero.
  • currentCulture: Obrigatório. Safra/cultura atual (Mín. 3 caracteres).
  • previousCulture: Obrigatório. Safra/cultura anterior (Mín. 3 caracteres).
  • coordinates: Obrigatório. O array de coordenadas precisa ter no mínimo 3 pontos para formar um polígono válido.
  • description: Opcional. Se enviado, mínimo de 3 caracteres.
Exemplo de Requisição (JSON)
{
  "fieldName": "Talhão Sul 01",
  "totalAreaHec": 120.5,
  "currentCulture": "Soja",
  "previousCulture": "Milho",
  "farmId": 1,
  "description": "Área de várzea",
  "coordinates": [
    { "latitude": -17.785, "longitude": -50.923 },
    { "latitude": -17.788, "longitude": -50.923 },
    { "latitude": -17.788, "longitude": -50.920 }
  ]
}
Respostas Possíveis
200 Sucesso: Retorna o Talhão (FieldResponse) criado.
400 Erro de Validação: Faltam campos ou formatos incorretos. 
{
  "coordinates": "No mínimo 3 coordenadas devem ser fornecidas.",
  "totalAreaHec": "A área total (totalAreaHec) deve ser maior que zero.",
  "fieldName": "O nome do campo (fieldName) é obrigatório."
}
404 Não Encontrado: A Fazenda informada não existe. 
{
  "detail": "Farm não encontrado com o id fornecido."
}
403 Proibido: Você não tem permissão para gerenciar esta fazenda.
POST /api/fields/from-file/ Criar Talhões via Arquivo GeoJSON
Funcionalidade de Importação em Lote: Lê um arquivo `.geojson` e cria todos os talhões (polígonos) automaticamente, mapeando os nomes e a área em hectares.
⚠️ Regras do Arquivo GeoJSON:
  • Permissão: Seu usuário deve ter a permissão de Gerenciamento da Fazenda (MANAGE_FARM).
  • Extensão: O arquivo DEVE ter a extensão .geojson.
  • Tamanho: O arquivo não pode exceder 5 MB.
  • Estrutura Interna: Deve conter uma lista de "features" (FeatureCollection).
  • Geometria: O tipo de geometria na feature deve ser "Polygon". Outros tipos são ignorados.
  • Propriedades: Cada polígono deve possuir as properties "name" (Nome do talhão) e "area" (Tamanho em hectares).
Parâmetros (Form-Data / Multipart)
NomeLocalTipoDescrição
farmIdQueryLongID da Fazenda que receberá os talhões.
fileFormDataFileO arquivo .geojson com os polígonos.
Respostas Possíveis
200 Sucesso: Retorna a Lista (Array) dos Talhões criados com sucesso.
400 Erro na Importação: Arquivo inválido ou regras não atendidas.
// Se o arquivo não for .geojson: 
{
  "detail": "Arquivo deve ter extensão .geojson"
}

// Se o arquivo for maior que 5MB: 
{
  "detail": "Arquivo muito grande, máximo permitido 5 MB"
}

// Se o JSON interno não tiver features: 
{
  "detail": "GeoJSON inválido: campo 'features' ausente ou não é um array"

500 Erro Interno: Falha ao tentar ler a estrutura de árvore do GeoJSON (Erro de parser).
404 Não Encontrado: Fazenda não existe.

PATCH /api/fields/{fieldId}/ Atualizar Dados do Talhão
Regra de Culturas: Se você enviar uma nova currentCulture (Cultura Atual), o sistema fará a substituição automaticamente, pegando a cultura antiga e movendo-a para a previousCulture (Cultura Anterior).
⚠️ Regras e Permissões:
  • Permissão: Requer permissão de Gerenciamento da Fazenda (MANAGE_FARM).
  • Parcial: Você pode enviar apenas os campos que deseja atualizar.
  • Coordenadas: Se for atualizar os pontos do polígono, você deve enviar um novo Array com no mínimo 3 coordenadas. Isso limpará as coordenadas antigas e registrará as novas.
Exemplo de Atualização Parcial
{
  "currentCulture": "Milho Safrinha",
  "description": "Atualizado em 2024"
}
Respostas Possíveis
200Sucesso: Retorna o Talhão atualizado.
400 Erro de Validação: Regra violada.
// Exemplo: Tentou limpar as coordenadas enviando menos de 3 pontos 
{
  "detail": "No mínimo 3 coordenadas devem ser fornecidas para atualizar o campo."
}
404Não Encontrado: Talhão inexistente.
403Proibido: Falta de permissão de gerente.
DELETE /api/fields/{fieldId}/ Excluir Talhão
Exclui permanentemente o Talhão e todas as suas coordenadas do banco de dados. Atenção: Quaisquer Lotes do ARVA vinculados a ele serão apagados em cascata.
Permissão: Apenas o Gerente da Fazenda pode deletar Talhões.
Respostas Possíveis
204Sucesso: Removido (Sem conteúdo de retorno).
404Não Encontrado: Talhão não existe.
403Proibido: Acesso negado.

Busca todos os Lotes (Batches do protocolo ARVA) que foram criados para este Talhão específico. Retorno paginado.
