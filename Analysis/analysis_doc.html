RvCarbon Arva 1.0.0 Protocolo

[ Base URL: https://api.rvcarbon.com.br/ ]

Gestão de Lotes (Batches) e Análises Agrícolas do protocolo ARVA.
Nota Importante: Esta API retorna Entidades Completas (Entities) diretamente nas respostas, não DTOs simplificados.

Analysis Batch Controller (Arva) Gestão de Lotes de Cultivo e Safras
POST /api/analysis/batches/ Criar Novo Lote (Safra)
Cria um novo ciclo de cultivo (Lote/Safra) para um Talhão específico.
Atenção: Os dados de criação são enviados todos juntos no mesmo JSON (JSON plano).
⚠️ Regras de Validação:
  • Permissão Necessária: Seu usuário deve ter a permissão de criar dados naquele talhão específico.
  • fieldId: Obrigatório. É o ID numérico do Talhão.
  • season: Obrigatório. A safra deve seguir estritamente o formato YYYY (ex: 2023) ou YYYY/YYYY (ex: 2023/2024).
  • culture: Obrigatório. Culturas permitidas: SOJA, CANA_DE_ACUCAR ou MILHO.
  • startDate: Obrigatório. Data em que o lote se inicia.
  • endDate: Obrigatório. Data em que o lote se encerra. A data de fim não pode ser anterior à data de início.
  • batchName: Obrigatório. Um nome descritivo para facilitar a identificação.
Dados para Envio (JSON)
{
  "fieldId": 55,
  "season": "2023/2024",
  "culture": "SOJA",
  "batchName": "Safra Verão 23/24",
  "startDate": "2023-09-01",
  "endDate": "2024-02-28",
  "manager": "Carlos (Opcional)",
  "note": "Observações do lote (Opcional)"
}
Respostas Possíveis
200 Sucesso: Retorna a entidade do Lote completa recém criada. 
{
  "id": 102,
  "culture": "SOJA",
  "season": "2023/2024",
  "batchName": "Safra Teste",
  "analysisMask": 2048,
  "isComplete": false
}
400 Erro de Validação: Dados enviados ferem as regras de negócio.
// Exemplo 1: Erros de campos 
{
  "season": "A safra deve estar no formato YYYY ou YYYY/YYYY",
  "fieldId": "O id do talhão (fieldId) é obrigatório",
  "culture": "A cultura (culture) é obrigatório"
}

// Exemplo 2: Datas Inconsistentes 
{
  "detail": "A data de fim (endDate) deve ser posterior à data de início (startDate)"
}
404 Não Encontrado: O Talhão referenciado (fieldId) não existe no banco de dados. 
{
  "detail": "Field não encontrado com o id fornecido."
}
403 Proibido: Seu usuário não tem permissão para criar lotes neste talhão.
PATCH /api/analysis/batches/{batchId}/ Atualizar Dados do Lote
⚠️ Regras e Permissões:
  • Permissão: Você deve ter permissão para editar todos os lotes da fazenda, ou ser o próprio criador deste lote.
  • Praticidade: Envie no JSON apenas os campos que você deseja alterar. O restante será mantido.
  • Datas: Se você alterar as datas, o sistema garantirá que a data de fim ainda seja maior ou igual à data de início.
Exemplo de Envio (JSON)
{
  "batchName": "Correção do Nome da Safra",
  "endDate": "2024-03-01"
}
Respostas Possíveis
200 Sucesso: Retorna o Lote com os dados atualizados.
400 Erro de Validação: Inconsistência nas datas informadas. 
{
  "detail": "A data de fim (endDate) deve ser posterior à data de início (startDate)"
}
404 Não Encontrado: O Lote referenciado não existe no banco de dados. 
{
  "detail": "Batch não encontrado com o id fornecido."
}
403 Proibido: Você não tem permissão para editar este lote.
GET /api/analysis/batches/ Listar Lotes de uma Fazenda
Retorna uma lista paginada de todos os lotes (ArvaBatch) pertencentes a uma fazenda específica. Inclui metadados como total de páginas e total de elementos.
Permissão: O usuário deve ter permissão de leitura (visualização) na Fazenda alvo.
Filtros (Query Params)
NomeObrigatórioDescrição
farmIdSimO ID numérico da Fazenda
pageNãoNúmero da página para paginação (Padrão: 0)
sizeNãoQuantidade de itens por página (Padrão: 10)
Respostas Possíveis
200Sucesso: Retorna uma lista paginada (Page<ArvaBatch>).
404 Não Encontrado: A Fazenda referenciada não existe no banco de dados. 
{
  "detail": "Farm não encontrado com o id fornecido."
}
403Proibido: Você não tem permissão para visualizar os dados desta fazenda.
GET /api/analysis/batches/{batchId}/ Buscar Lote por ID
Permissão Necessária: Permissão de leitura/visualização no Lote específico.
Respostas Possíveis
200Sucesso: Retorna a entidade do Lote solicitada.
404 Não Encontrado: O Lote com este ID não existe. 
{
  "detail": "Batch não encontrado com o id fornecido."
}

DELETE /api/analysis/batches/{batchId}/ Excluir Lote (Deleção em Cascata)
Exclui um lote permanentemente.
Atenção: Como as análises estão atreladas ao lote, excluir o lote excluirá automaticamente todas as análises pertencentes a ele.
⚠️ Permissão Crítica: Seu usuário deve ter autorização para excluir todos os dados do lote, ou ser o proprietário que criou o próprio lote.
Respostas Possíveis
204Sucesso: Lote e análises removidos. (Sem conteúdo no retorno).
404 Não Encontrado: O Lote com este ID não existe. 
{
  "detail": "Batch não encontrado com o id fornecido."
}
403Proibido: Falta de permissão para exclusão.
GET /api/analysis/batches/mine/ Meus Lotes
Busca todos os lotes que foram criados pelo usuário que está atualmente logado.
Respostas Possíveis
200Sucesso: Retorna uma lista paginada (Page<ArvaBatch>).

Dica: Altere a caixa seletora abaixo para ver o corpo (JSON), as regras específicas e os erros retornados para cada tipo de análise!
Selecione o Tipo de Análise
Exemplo de JSON para Envio (Base Genérica)
Respostas Possíveis

PATCH /api/analysis/{analysisId}/ Atualizar Análise
⚠️ Regras Importantes:
  • Polimorfismo Ativo: Você é obrigado a enviar o analysisType na requisição, mesmo que seja apenas para atualizar as anotações.
  • Tipo Inalterável: O sistema lançará erro se você tentar enviar um analysisType diferente do tipo original que a análise foi criada (Ex: Você não pode transformar uma Colheita num Plantio).
  • Atualização Parcial: Os campos específicos que você não enviar serão mantidos com os valores antigos.
  • Permissão: Permissão para editar todos os dados do lote, ou ter sido o autor dele.
Exemplo de Atualização
{
  "analysisType": "PLANTING_OPERATION",
  "notes": "Correção: Plantio atrasou 1 dia devido a chuvas",
  "endDate": "2023-10-03"
}
Respostas Possíveis
200Sucesso: Retorna a entidade com os dados novos salvos.
400 Erro de Tipo Incompatível: Ocorre se você enviou o JSON de um tipo para atualizar uma análise de outro tipo. 
{
  "detail": "AnalysisTypeMismatchException: Analysis ID 501..."
}
400 Erro de Datas: Validação falhou (A nova data de início ficou posterior à data de término existente). 
{
  "detail": "A data de início não pode ser posterior à data de término."
}
404 Não Encontrado: 
{
  "detail": "Analysis não encontrado com o id fornecido."
}
403Proibido: Falta de permissão para edição.

GET /api/analysis/xls/ Exportar Relatório Excel
Gera um arquivo físico .xlsx (Planilha Excel) pronto para download, contendo todo o histórico de análises de um determinado período.
Parâmetros Obrigatórios da URL
NomeDescrição

endData Final do período (Formato: yyyy-MM-dd)
farmIdObrigatório informar pelo menos o ID da Fazenda OU o ID do Talhão (fieldId).
Respostas Possíveis
200Sucesso: Arquivo binário transferido (Content-Type: application/vnd.openxmlformats...).
400 Erro de Validação: 
{
  "detail": "O farmId ou fieldId é obrigatório"
}
403Proibido: Acesso de visualização negado à Fazenda ou Talhão.
