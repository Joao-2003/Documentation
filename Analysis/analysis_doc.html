RvCarbon Arva 1.0.0 Protocolo

[ Base URL: https://api.rvcarbon.com.br/ ]

Gestão de Lotes (Batches) e Análises Agrícolas do protocolo ARVA.
Nota Importante: Esta API retorna Entidades Completas (Entities) diretamente nas respostas, não DTOs simplificados.

Batch Controller Gestão de Lotes/Safras (Herdado)
POST /api/analysis/batches/ Criar Novo Lote
Cria um novo ciclo de cultivo (Lote/Safra) para um Talhão específico.
Atenção: JSON Plano (Flattened). Os campos de nome e data ficam na raiz do JSON junto com os IDs.
⚠️ Regras de Validação:
  • fieldId: Obrigatório. ID do Talhão.
  • season: Obrigatório. Formato Rígido: YYYY ou YYYY/YYYY.
  • culture: Obrigatório. Enum: SOJA, CANA_DE_ACUCAR, MILHO.
  • startDate: Obrigatório (Data Início).
  • endDate: Obrigatório (Data Fim). Deve ser >= Data Início.
  • batchName: Obrigatório (Não pode ser vazio).
Dados para Envio (JSON)
{
  "fieldId": 55,
  "season": "2023/2024",
  "culture": "SOJA",
  "batchName": "Safra Verão 23/24",
  "startDate": "2023-09-01",
  "endDate": "2024-02-28",
  "manager": "Carlos (Opcional)",
  "note": "Observações do lote (Opcional)"
}
Respostas
200 Sucesso: Retorna a entidade ArvaBatch criada.
{ "id": 102, "culture": "SOJA", "season": "2023/2024", "analysisMask": 2048, ... }
400 Erro na Requisição (Múltiplas Causas):
// 1. Validação de Formato (Safra inválida):
{ "season": "A safra deve estar no formato YYYY ou YYYY/YYYY" }

// 2. Regra de Negócio (Datas inválidas):
{ "detail": "A data de fim (endDate) deve ser posterior à data de início (startDate)" }
PATCH /api/analysis/batches/{batchId}/ Atualizar Lote
Permissão: EDIT_ALL_BATCH_DATA ou EDIT_OWN_BATCH_DATA.
Envie apenas os campos que deseja alterar. 
{ "batchName": "Correção Nome", "endDate": "2024-03-01" }

{ "detail": "A data de fim (endDate) deve ser posterior à data de início (startDate)" }

Analysis Arva Controller Gestão de Análises Agrícolas
POST /api/analysis/ Criar Nova Análise
Polimorfismo: O JSON enviado deve conter o campo analysisType. Este campo define quais outros campos específicos são esperados.
⚠️ Regras Comuns (DataAnalysisBaseRequest):
  • batchId: Obrigatório e Positivo.
  • analysisType: Obrigatório (Enum). Define o subtipo.
  • startDate: Obrigatório. Não pode ser futura.
  • endDate: Opcional. Não pode ser futura. Se existir, deve ser >= startDate.
  • collectedBy: Opcional. Min 2 caracteres.
Dados para Envio (Genérico)
{
  "analysisType": "PLANTING_OPERATION",
  "batchId": 102,
  "startDate": "2023-10-01",
  "endDate": "2023-10-02",
  "notes": "Plantio de soja safra verão",
  "collectedBy": "Técnico João",
  // + Campos específicos do PLANTING_OPERATION aqui (no mesmo nível)
}
Respostas
200 Sucesso: Retorna a entidade Analysis criada (estrutura completa).
{ "id": 501, "analysisType": "PLANTING_OPERATION", "batch": { "id": 102 }, ... }
400 Erro (Validação / Regra de Negócio):
// 1. Campos inválidos (Datas futuras):
{ "startDate": "A data de início (startDate) não pode ser futura." }

// 2. Consistência de Datas (ValidationPoolException):
{ "detail": "A data de término não pode ser anterior à data de início." }
403Proibido: Você não tem permissão para editar este lote.
PATCH /api/analysis/{analysisId}/ Atualizar Análise
⚠️ Regras: Envie apenas os campos que deseja alterar. O tipo da análise não pode ser mudado.
Permissão: Requer EDIT_ALL_BATCH_DATA na Análise ou EDIT_OWN_BATCH_DATA no Batch. 
{
  "notes": "Correção: Plantio atrasou 1 dia",
  "endDate": "2023-10-03"
}
Respostas
200Sucesso: Retorna a entidade atualizada.
400 Erro: Tipo de análise incompatível.
{ "detail": "AnalysisTypeMismatchException: Analysis ID 501..." }
400 Erro: Validação falhou (Datas inconsistentes).
{ "detail": "A data de início não pode ser posterior à data de término." }
403Proibido: Falta de permissão.
DELETE /api/analysis/{analysisId}/ Excluir Análise
Permissão Crítica: Requer DELETE_ALL_BATCH_DATA ou DELETE_OWN_BATCH_DATA. A exclusão é permanente.
Respostas
204Sucesso: Removido (Sem conteúdo).
403Proibido: Falta de permissão.
