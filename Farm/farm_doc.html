RvCarbon API 1.0.0 Fazendas

[ Base URL: https://api.rvcarbon.com.br/ ]

Gestão central de Fazendas (Farms) e Membros da equipe. Esta seção permite cadastrar propriedades, gerenciar usuários vinculados à fazenda e seus níveis de permissão.

Farm Controller Gestão de Fazendas e Membros
POST /api/farms/ Criar Nova Fazenda
Cria uma nova fazenda vinculando-a a um "Proprietário de Fazenda" (Farm Owner) existente. O usuário que criar a fazenda torna-se automaticamente o "Gerente" dela.
⚠️ Regras de Validação (Obrigatórios na Criação):
  • farmName: Obrigatório. Mínimo de 3 caracteres.
  • state & city: Obrigatórios (Estado e Cidade).
  • responsible: Obrigatório. Mínimo de 2 caracteres.
  • responsiblePhoneNumber: Obrigatório. Deve ser no formato (XX) XXXXX-XXXX.
  • ownerId: Obrigatório e deve ser maior que zero (ID do Proprietário).
  • totalAreaHectares: Obrigatório. Deve ser maior que zero.
  • businessEmail: Opcional, mas se enviado deve ser um e-mail válido com mais de 3 caracteres.
  • cpfCnpj: Opcional, mas se enviado deve ser em formato válido (com pontuação).
Exemplo de Requisição (JSON)
{
  "farmName": "Fazenda Boa Vista",
  "state": "SP",
  "city": "Campinas",
  "responsible": "Carlos Alberto",
  "responsiblePhoneNumber": "(11) 98765-4321",
  "ownerId": 10,
  "businessEmail": "contato@boavista.com",
  "cpfCnpj": "12.345.678/0001-99",
  "totalAreaHectares": 1500.5
}
Respostas Possíveis
200 Sucesso: Retorna a entidade Fazenda criada (FarmResponse). 
{
  "id": 1,
  "farmName": "Fazenda Exemplo",
  "active": true,
  "ownerId": 10,
  "totalAreaHectares": 1500.5,
  "userManagerName": "usuario_que_criou",
  // ... demais campos ...
}
400 Erro de Validação: Faltam campos ou o formato está incorreto. 
{
  "farmName": "O nome da fazenda (farmName) é obrigatório.",
  "responsiblePhoneNumber": "numero de telefone invalido (phone), ele deve estar no formato (11) 11111-1111",
  "totalAreaHectares": "A área total (totalAreaHectares) deve ser maior que zero."
}
404 Não Encontrado: O Proprietário (ownerId) não existe. 
{
  "detail": "FarmOwner não encontrado com o id fornecido."
}
PATCH /api/farms/{farmId}/ Atualizar Dados da Fazenda
Permissões Necessárias: É necessário possuir a Permissão de Gerenciamento da Fazenda.
Importante: Para atualizações, todos os campos são opcionais. Envie apenas o que deseja modificar. Mas se enviar, as regras de validação (tamanho, formato de e-mail/telefone) continuam sendo aplicadas!
Exemplo de Requisição (JSON)
{
  "farmName": "Fazenda Boa Vista Editada",
  "totalAreaHectares": 1600.0
}
Respostas Possíveis
200 Sucesso: Retorna a Fazenda atualizada.
400 Erro de Validação: Algum campo enviado não atende às regras (ex: telefone inválido).
404 Não Encontrado: A Fazenda com o ID fornecido não existe.
403 Proibido: Seu usuário não é o gerente da fazenda.
GET /api/farms/{farmId}/ Buscar Fazenda por ID
Permissão: Necessária Permissão de Leitura/Visualização da Fazenda.
Respostas Possíveis
200Sucesso: Retorna a entidade detalhada da Fazenda.
404Não Encontrado: Fazenda não existe.
403Proibido: Você não faz parte desta fazenda.
DELETE /api/farms/{farmId}/ Desativar Fazenda
Ao invés de excluir os dados do banco permanentemente, a Fazenda é Desativada. As estatísticas do Proprietário (quantidade de fazendas e área total) são reduzidas automaticamente.
Permissão Crítica: Somente o usuário com Permissão de Gerenciamento da Fazenda pode realizar esta ação.
Respostas Possíveis
204Sucesso: Desativada. (Sem corpo de retorno).
404Não Encontrado: A Fazenda não existe.
403Proibido: Acesso negado.

Retorna uma lista contendo todas as Fazendas ativas em que o usuário autenticado faz parte da equipe (seja como Gerente ou Leitor).
Respostas Possíveis
200 Sucesso: Retorna uma Lista em Array de Fazendas. 
[
  {
    "id": 1,

    "active": true
  }

GET /api/farms/by-owner/{ownerId}/ Listar Fazendas por Proprietário
Lista as fazendas pertencentes a um Proprietário específico, com a condição de que o usuário logado também faça parte da equipe destas fazendas.
Parâmetros
NomeObrigatórioDescrição
ownerIdSim (Path)ID numérico do Proprietário (FarmOwner)
statusNão (Query)Filtro de Status. Valores: ACTIVE (padrão), INACTIVE, ALL.
Respostas Possíveis
200Sucesso: Lista de Fazendas do proprietário escolhido.
Gestão de Equipe (Membros da Fazenda)
POST /api/farms/{farmId}/members/ Adicionar Membro na Equipe
⚠️ Regras e Permissões:
  • Permissão: Apenas o Gerente da fazenda pode adicionar novos membros.
  • Obrigatório: O username da pessoa a ser convidada e o nível de acesso (role).
  • Limitação: Não é permitido adicionar alguém já como MANAGER_ROLE por este endpoint.
  • Duplicidade: O sistema bloqueia a adição de um usuário que já é membro.
Exemplo de Requisição (JSON)
{
  "username": "tecnico_joao",
  "role": "VIEWER_ROLE"
}
Respostas Possíveis
200 Sucesso: Usuário adicionado à fazenda. 
{
  "memberId": 22,
  "username": "joao_silva",
  "completeName": "João da Silva",
  "email": "joao@email.com",
  "role": "RESTRICTED_ROLE"
}
400 Erro de Negócio / Validação:
// Se tentar dar permissão de MANAGER: 
{
  "detail": "Não é permitido atribuir a role MANAGER_ROLE"
}

// Se o usuário já estiver na equipe: 
{
  "detail": "This user is already member of farm"
}
404Não Encontrado: A Fazenda ou o Usuário convidado não existem.
403Proibido: Somente gerentes podem adicionar membros.
PATCH /api/farms/{farmId}/members/ Atualizar Permissão do Membro
⚠️ Regras de Negócio:
  • Permissão: Apenas o Gerente da fazenda pode alterar os níveis de acesso.
  • Proteção: Ninguém pode alterar a permissão do próprio Gerente (Manager).
  • Segurança: Não é permitido promover um membro para `MANAGER_ROLE` por este endpoint. A transição de liderança requer outro fluxo.
Exemplo de Requisição (JSON)
{
  "username": "tecnico_joao",
  "role": "MANAGER_AUX_ROLE"
}
Respostas Possíveis
200Sucesso: Permissão atualizada com sucesso.
400 Erro de Negócio:
// Se tentar alterar a permissão do Gerente Principal: 
{
  "detail": "Cannot assign role to manager of farm"
}
404Não Encontrado: Usuário não faz parte da equipe ou fazenda não existe.
403Proibido: Apenas o gerente pode fazer isso.
DELETE /api/farms/{farmId}/members/{memberId}/ Remover Membro da Equipe
Remove o acesso de um usuário à fazenda específica. Ele não poderá mais interagir com os dados deste local.
Permissão: Apenas o Gerente da fazenda pode expulsar membros.
Respostas Possíveis
204Sucesso: Membro removido.
404Não Encontrado: Vínculo de membro ou Fazenda inexistentes.
403Proibido: Apenas gerentes.
GET /api/farms/{farmId}/members/ Listar Todos os Membros
Permissão: Requer Permissão de Leitura/Visualização na Fazenda.
Respostas Possíveis
200 Sucesso: Retorna a Lista de Membros da Equipe (Array de FarmMemberResponse).
404Fazenda não encontrada.
403Você não faz parte da equipe.
GET /api/farms/{farmId}/owner/ Ver Dados do Proprietário
Traz os detalhes de contato do Proprietário (Farm Owner) associado à Fazenda.
Permissão: Requer Permissão de Leitura/Visualização na Fazenda.
Respostas Possíveis
200 Sucesso: Retorna o perfil do Proprietário.
404 Não Encontrado: Não há proprietário vinculado ou a fazenda não existe. 
{
  "detail": "FarmOwner não encontrado com o id fornecido."
}
403Acesso negado.
GET /api/farms/{farmId}/batches/ Listar Lotes da Fazenda
Busca todos os Lotes (Batches) globais associados a esta Fazenda. O Retorno é Paginado.
Parâmetros
NomeLocalObrigatórioDescrição
farmIdpathSimO ID numérico da Fazenda
pagequeryNãoNúmero da página para paginação (Padrão: 0)
sizequeryNãoQuantidade de itens por página (Padrão: 10)
Respostas Possíveis
200Sucesso: Lista paginada com os Lotes (Page<Batch>).
404Não Encontrado: A Fazenda não existe.
403Proibido: Acesso de visualização negado.
Schemas (Modelos de Dados da Fazenda)
RoleEnum (Níveis de Acesso da Equipe) ▼
MANAGER_ROLE // Gerente: Criador da fazenda. Acesso total. Promove/expulsa membros.
MANAGER_AUX_ROLE // Subgerente: Cria, edita e deleta QUALQUER lote. Não gere equipe.
RESTRICTED_ROLE // Operador: Cria lotes, mas só pode editar e deletar OS PRÓPRIOS lotes que criou.
VIEWER_ROLE // Leitor: Apenas visualização de relatórios e painéis.
