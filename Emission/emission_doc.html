RvCarbon GHG 1.0.0 Protocolo de Emissões

[ Base URL: https://api.rvcarbon.com.br/ ]

Gestão de Lotes de Emissões e Gases de Efeito Estufa (Protocolo GHG).
Nota Importante: Esta API retorna Entidades Completas diretamente nas respostas (incluindo o cálculo de métricas CO2e).

GHG Batch Controller Gestão de Lotes de Emissão (Atrelados à Fazenda)
POST /api/emissions/batches/ Criar Novo Lote de Emissões
Cria um novo Lote (Batch) destinado a agrupar registros de emissões de gases. Diferente do ARVA, os lotes do GHG são vinculados diretamente a uma Fazenda (farmId) e não a um Talhão.
⚠️ Regras de Validação:
  • Permissão Necessária: Seu usuário deve ter a permissão para criar dados na Fazenda referenciada.
  • farmId: Obrigatório. É o ID numérico da Fazenda.
  • startDate: Obrigatório. Data de início do período analisado.
  • endDate: Obrigatório. A data de fim não pode ser anterior à data de início.
  • batchName: Obrigatório. Um nome para o lote (Ex: "Inventário de Emissões 2023").
Dados para Envio (JSON)
{
  "farmId": 15,
  "batchName": "Inventário de Emissões 2023",
  "startDate": "2023-01-01",
  "endDate": "2023-12-31",
  "manager": "Engenheiro Marcos",
  "note": "Observações opcionais"
}
Respostas Possíveis
200 Sucesso: Retorna a entidade Lote GHG criada (os totais de gases iniciam zerados). 
{
  "id": 305,
  "batchName": "Inventário 2023",
  "co2": 0.0,
  "ch4": 0.0,
  "co2eTotal": 0.0,
  "isComplete": false
}
400 Erro de Validação: Inconsistência nos dados enviados.
// Exemplo: Inconsistência de Datas 
{
  "detail": "A data de fim (endDate) deve ser posterior à data de início (startDate)"
}

// Exemplo: Faltou Farm ID 
{
  "farmId": "O campo farmId é obrigatório"
}
404 Não Encontrado: A Fazenda informada não existe no banco de dados.
403 Proibido: Você não tem permissão para criar lotes nesta fazenda.
PATCH /api/emissions/batches/{batchId}/ Atualizar Lote de Emissões
⚠️ Regras e Permissões:
  • Permissão: Autorização para editar todos os lotes, ou ser o próprio criador do lote.
  • Praticidade: Envie apenas os campos que deseja alterar (ex: apenas o note).
  • Atenção: Se for alterar as datas, garanta que a data fim seja maior ou igual à data de início.
Exemplo de Atualização Parcial
{
  "note": "Atualizado para incluir novos relatórios."
}
Respostas Possíveis
200Sucesso: Retorna a entidade do lote atualizada.
400 Erro de Validação: Inconsistência de datas. 
{
  "detail": "A data de fim (endDate) deve ser posterior à data de início (startDate)"
}
404 Não Encontrado: O lote não existe. 
{
  "detail": "Batch não encontrado com o id fornecido."
}
403Proibido: Acesso negado.

Retorna uma lista paginada dos lotes de emissão vinculados a uma fazenda.

Permissão: O usuário precisa ter direito de visualização neste Lote específico.
Respostas Possíveis

404 Não Encontrado:

DELETE /api/emissions/batches/{batchId}/ Excluir Lote (Deleção em Cascata)
Ao excluir um Lote de Emissões, TODOS os registros de gases atrelados a ele serão permanentemente apagados do banco de dados em cascata.
⚠️ Permissão Crítica: Necessário nível de acesso para deleção global de lote ou ser o proprietário criador do lote.
Respostas Possíveis
204Sucesso: Removido com segurança (Sem corpo).
404 Não Encontrado: 
{
  "detail": "Batch não encontrado com o id fornecido."
}
403Proibido: Nível de acesso insuficiente para exclusão.
GET /api/emissions/batches/mine/ Meus Lotes de Emissão
Busca todos os lotes GHG que foram criados exclusivamente pelo usuário atual logado (Paginado).
Respostas Possíveis
200Sucesso: Retorna uma lista paginada de Lotes (Page<EmissionBatchGhg>).
GHG Emissions Controller Gestão dos Registros de Gases
POST /api/emissions/ Registrar Emissão de Gases
Dinâmica de Cálculo: Ao salvar um registro, o backend recalculará automaticamente as métricas totais e a equivalência em Carbono (CO2eT), e em seguida atualizará a soma total do Lote pai.
⚠️ Regras de Validação Absolutas (EmissionGHGRequest):
  • batchId: Obrigatório e Maior que zero.
  • emissionType: Obrigatório (Enum). Indica a categoria da emissão (ex: ENERGY_AND_FUEL).
  • co2: Obrigatório. O valor de Dióxido de Carbono nunca pode ser negativo.
  • Demais Gases (ch4, n2o, sf6, hfc*, pfc*, etc.): Opcionais, porém se forem enviados, nunca podem ser negativos ( >= 0 ).
Exemplo de Envio (JSON)
{
  "batchId": 305,
  "emissionType": "ENERGY_AND_FUEL",
  "note": "Consumo de gerador a diesel",
  "co2": 150.5,
  "ch4": 2.1,
  "n2o": 0.5,
  // Os campos que não forem informados ficarão zerados/nulos no banco
}
Respostas Possíveis
200 Sucesso: Retorna a entidade salva, com os cálculos de CO2e finalizados. 
{
  "id": 99,
  "emissionType": "ENERGY_AND_FUEL",
  "co2": 150.5,
  "co2eT": 291.8, // (Exemplo de resultado do cálculo GWP)
  "totalBiogenicRemoval": 0.0
}
400 Erro de Validação: Violação das regras de não-negatividade.
// Exemplo de Mapa de Erros (Todas as possibilidades): 
{
  "batchId": "O id da batch de emissão (batchId) é obrigatório", // ou "precisa ser positivo"
  "emissionType": "O valor do tipo de emissão (emissionType) não pode ser nulo",
  "co2": "O valor de CO2 (co2) é obrigatório", // ou "não pode ser negativo"
  "ch4": "O valor de CH4 (ch4) não pode ser negativo",
  "sf6": "O valor de SF6 (sf6) não pode ser negativo",
  "nf3": "O valor de NF3 (nf3) não pode ser negativo",
  "n2o": "O valor de N2O (n2o) não pode ser negativo",
  "emiCo2Bio": "O valor de emissões de CO2 biogênico (emiCo2Bio) não pode ser negativo",
  "remoCo2Bio": "O valor de remoções de CO2 biogênico (remoCo2Bio) não pode ser negativo",
  "hfc23": "O valor de HFC-23 (hfc23) não pode ser negativo",
  // ... (E exatamente a mesma mensagem "não pode ser negativo" para todos os 18 HFCs e 9 PFCs)
  "pfc": "O valor de PFC (pfc) não pode ser negativo",
  "trifluorometilPentafluoretoEnxofre": "O valor de Trifluorometil pentafluoreto de enxofre (...) não pode ser negativo",
  "perfluorociclopropano": "O valor de Perfluorociclopropano (...) não pode ser negativo"
}
404 Não Encontrado: O Lote não foi encontrado no banco. 
{
  "detail": "Batch não encontrado com o id fornecido."
}
403Proibido: Acesso negado para edição.
PATCH /api/emissions/{emissionId}/ Atualizar Registro de Emissão
⚠️ Regras Importantes:
  • Recálculo Automático: Os cálculos do registro e a soma do Lote correspondente serão recalculados automaticamente após a atualização.
  • Gases: Os campos de gases que você passar no JSON substituirão os antigos. Lembre-se, não podem ser menores que zero.
Exemplo de Atualização
{
  "co2": 180.0,
  "note": "Valor de CO2 ajustado após re-medição"
}
Respostas Possíveis
200Sucesso: Retorna a entidade com os valores novos salvos e recalculados.
400 Erro de Validação: Gás com valor negativo enviado. 
{
  "ch4": "O valor de CH4 (ch4) não pode ser negativo"
}
404 Não Encontrado: A emissão referenciada não existe. 
{
  "detail": "EmissionBatchGhg não encontrado com o id fornecido." // A Exceção aponta para o nome da classe usada na busca
}
403Proibido: Falta de permissão para edição.
DELETE /api/emissions/{emissionId}/ Excluir Emissão
Exclui um registro de gases específico permanentemente e engatilha o recálculo do Lote subtraindo o valor excluído.
Respostas Possíveis
204Sucesso: Removido (Sem corpo de resposta).
404 Não Encontrado: Registro não existe.
403Proibido: Acesso negado.

Schemas (Modelos de Dados GHG)
BatchFarmRequest (Criar Lote) ▼
// Campos Genéricos Desembrulhados (Unwrapped)
farmId: long (obrigatório)
startDate: date (obrigatório, yyyy-MM-dd)
endDate: date (obrigatório, yyyy-MM-dd, >= startDate)
batchName: string (obrigatório)
manager: string (opcional)
note: string (opcional)
EmissionBatchGhg (Entidade Lote Final) ▼
id: long
batchName: string
startDate: date
endDate: date
isComplete: boolean
// Totais calculados
co2: float
ch4: float
hfc: float
pfc: float
sf6: float
nf3: float
n2ho: float
co2eTotal: float
biogenicCo2Emissions: float
biogenicCo2Removals: float
EmissionGHGRequest (Requisição de Gases) ▼
batchId: long (Obrigatório)
emissionType: enum (Obrigatório)
note: string
// Todos abaixo são do tipo float >= 0. Apenas co2 é obrigatório.
co2, ch4, sf6, nf3, n2o, emiCo2Bio, remoCo2Bio
// HFCs
hfc23, hfc32, hfc41, hfc125, hfc134, hfc134a, hfc143, hfc143a, hfc152, hfc152a, hfc161, hfc227ea, hfc236cb, hfc236ea, hfc236fa, hfc245ca, hfc245fa, hfc365mfc, hfc4310mee
// PFCs
pfc, pfc14, pfc116, pfc218, pfc318, pfc3110, pfc412, pfc514, pfc918, trifluorometilPentafluoretoEnxofre, perfluorociclopropano
